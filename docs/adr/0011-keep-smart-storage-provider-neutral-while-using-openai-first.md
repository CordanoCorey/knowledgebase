# Keep Smart Storage Provider-Neutral While Using OpenAI First

Smart Storage will keep its durable Smart Storage Contract provider-neutral while the first LLM-backed execution adapter calls OpenAI's Responses API. Deterministic application logic remains the local preview, scaffold, and fallback layer, and the OpenAI model is configurable by environment so cost and quality can be tuned without changing contract-shaped Silver Layer records; this leaves room for a later self-hosted proprietary model to replace the adapter without rewriting Bronze, Silver, or Gold domain data.
